# Troubleshooting for Analysts

## Common Issues

| Issue | Solution |
|-------|----------|
| Connection timeout | Check Jupyter is running; refresh page |
| Out of memory | Add `LIMIT`; reduce data scope |
| Slow query | Add filters; check [Best Practices](./best-practices.md) |
| Table not found | Verify table name; check catalog |
