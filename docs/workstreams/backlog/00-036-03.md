# 00-036-03: Extract Airflow Templates into Parent with Independent Flag

Feature: F036 Chart Refactor
Phase: 2
Status: Backlog

## Goal

Перенести Airflow templates (webserver, scheduler, configmap, dags-configmap, postgresql)
из subchart в `charts/spark-3.5/templates/airflow/`.
Условие: `airflow.enabled` (independent от standalone.enabled).
DAGs переносятся как ConfigMap.
Airflow PostgreSQL опционален — по умолчанию используется external (shared spark-base).

## Scope Files

- charts/spark-3.5/templates/airflow/webserver.yaml (new)
- charts/spark-3.5/templates/airflow/scheduler.yaml (new)
- charts/spark-3.5/templates/airflow/configmap.yaml (new)
- charts/spark-3.5/templates/airflow/dags-configmap.yaml (new)
- charts/spark-3.5/templates/airflow/postgresql.yaml (new)
- charts/spark-3.5/templates/_helpers.tpl (airflow helpers)
- charts/spark-3.5/values.yaml (airflow section)
- charts/spark-3.5/dags/ (move from subchart)
- charts/spark-3.5/charts/spark-standalone/templates/airflow/ (delete)

## Dependencies

- 00-036-02: Standalone flattened (subchart partially empty)

- [ ] `charts/spark-3.5/values.yaml` содержит `airflow: { enabled: false, ... }`
