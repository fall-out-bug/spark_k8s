# 00-036-11: CI Helm Template Gates for All Deploy Modes

Feature: F036 Chart Refactor
Phase: 5
Status: Backlog

## Goal

Добавить CI job который на каждый PR запускает `helm template` и `helm lint`
для всех 5 mode combos + demo preset. Это предотвращает регрессии в рендеринге
без необходимости запускать полную матрицу 320 на каждый PR.

## Scope Files

- .github/workflows/ci-charts.yml (update or create)
- scripts/validate-chart-modes.sh (new)

## Dependencies

- 00-036-05: All chart changes done

## Acceptance Criteria

- [ ] `scripts/validate-chart-modes.sh` запускает helm template + helm lint для:
  - connect-only: `connect.enabled=true`
  - connect+standalone: `connect.enabled=true, standalone.enabled=true`
  - kubernetes: `kubernetes.enabled=true`
  - standalone: `standalone.enabled=true`
  - demo: `-f presets/demo-full-spark-infra.yaml`
  - all-disabled: defaults (nothing enabled)
- [ ] Каждый template render проверяет: exit code 0, no empty output, expected resource count
- [ ] CI workflow вызывает этот скрипт на push/PR
- [ ] Скрипт проходит shellcheck -S warning
- [ ] Скрипт exit code != 0 если хотя бы один mode fails
