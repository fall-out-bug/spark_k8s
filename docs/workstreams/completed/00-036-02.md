# 00-036-02: Flatten Standalone Subchart into Parent Templates

Feature: F036 Chart Refactor
Phase: 2
Status: Backlog

## Goal

Перенести master.yaml, worker.yaml, rbac.yaml, serviceaccount.yaml из subchart
`charts/spark-standalone/` в `charts/spark-3.5/templates/standalone/`.
Условие: `standalone.enabled`. Удалить subchart dependency из Chart.yaml.
После этого WS subchart больше не рендерит master+workers — всё в parent.

## Scope Files

- charts/spark-3.5/Chart.yaml
- charts/spark-3.5/Chart.lock
- charts/spark-3.5/templates/standalone/master.yaml (new)
- charts/spark-3.5/templates/standalone/worker.yaml (new)
- charts/spark-3.5/templates/standalone/rbac.yaml (new)
- charts/spark-3.5/templates/standalone/serviceaccount.yaml (new)
- charts/spark-3.5/templates/_helpers.tpl (new helpers)
- charts/spark-3.5/values.yaml (standalone section, defaults false)
- charts/spark-3.5/charts/spark-standalone/ (delete master+worker templates)
- charts/spark-3.5/charts/spark-standalone-0.1.0.tgz (rebuild or delete)
